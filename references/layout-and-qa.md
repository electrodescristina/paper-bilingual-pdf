# 对照排版与检查的具体规则

## 从原文位置恢复逻辑顺序

保存两层信息：逻辑段落 ID 与原 PDF 的片段坐标。不要用抽取块 ID 充当未经核对的段落 ID。

原稿可能出现：

- 双栏读取顺序交错，图注插入正文中间。
- 根号单独成块，其后的数字与下一个段落合成一块。
- 矩阵括号与元素分属多个块，正文上标伸进上一行包围盒。
- 一段跨页，或一个块包含两段正文。

通过页面图像和行坐标确认，然后合并/拆分。除去仅因换行产生的断词，不能删除真实连字符、负号或上下标。

## 共享分页，而非各排各的

重排模式的对应单元可由一对段落、一项列表、一组公式与解释或一幅图与图注构成。

1. 使用最终字体和可用宽度测量两侧的实际高度。
2. 对应单元高度取两侧较高值，再加入间距；双方共用同一个起点。
3. 当前页放不下时，两侧一起换页。长段或长表必须拆分时，在对应语义边界拆分，并标记续接；不要按相同字符数截断。
4. 一侧已经结束、另一侧需要续页时，明确标识同一原文单位的续译关系；不能借空位提前排入另一段而造成假对应。
5. 原文页码另作来源标记，不冒充新文件的页码。

原页并排模式优先把整张英文原页作为一个矢量对象嵌入左侧。中文布局空间不足时，按内容成组重排或增加清晰标识的对应页；必要时扩大页面。不要截断译文或一味缩小字号。

## 字号、行距和中文显示

字号以 PDF 物理点数和实际阅读体验判断，不能只看缩略图。正文通常可从 10.5–12 pt 起步，图注约 9–10 pt；这些是起点而非通用合格线。为对齐保留适量空白是正常的。

正文严重缩小、同类正文各段字号差异明显、图注无法正常阅读时，先改布局。检查中文行首禁排标点、孤立末行、英文单词断开、数值与单位分离，以及公式上下标被换到下一行。

中文字体不一定覆盖 ∇、∂、−、∗、帽号、希腊字母和上下标。逐个验证实际使用字形，必要时使用数学字体或原始公式对象。存在字体文件不代表字形完整；PDF 文本提取成功也不代表字形显示正确。

## 在原页上替换文本时的风险

若采用保留图形、替换文字的方式：

- **擦除范围与排入范围分开保存**。把中文排入范围移到正确位置，不代表原英文擦除区域也应随之移动。
- 大矩形遮盖可能抹掉公式、图注、曲线或下一段；根据真实文字范围处理，并检查边界。
- 先恢复所有需要保留的公式与图形，再排译文；恢复原始裁剪区域时，不能把周围英文碎片重新带回来。
- 只覆盖白色矩形可能留下隐藏的英文文本层。检查选择、复制、搜索；尽量避免不可见重复文本，不以文本提取的“完整”掩盖被盖住的内容。
- 不能以“每个文本框内部都放得下”作为不重叠的证明。检查最终渲染的字形/行范围与相邻段落、公式和图片的交集。
- 图内翻译覆盖属于预期的图文叠加，只对明确识别的对象允许重叠；不要全局关闭碰撞检查。

## 检查顺序和证据

1. **覆盖清单**：核对全部原文逻辑单位与两侧输出位置。图注、脚注和参考文献单独计数，不含糊归入“正文”。
2. **语义复核**：以原文为准核实每个单位，保存未解决问题；机器几何检查不能替代这一项。
3. **文本与字体**：验证译文字符进入最终文件，无替代字符或缺字；核对符号和复制文本。字符计数相同仍可能有漏译、错译或顺序错误。
4. **几何检查**：以最终实际范围检查越界、溢出、意外重叠和对应单元起点；逐一说明允许的图内叠加。
5. **全部页面渲染**：逐页观察图文关系、左右对应和连续性。重点放大双栏转单栏处、跨页句子、长表、根号、矩阵、图注和参考文献。
6. **原稿保真比对**：原页嵌入模式下，把左侧与源页以相同尺寸和渲染设置比较。细小抗锯齿差异应检查位置和程度，而不是随意设置一个能通过的差异阈值。记录这是原文保真检查，不是译文正确性检查。
7. **最终文件复验**：重开最终路径下的 PDF，检查页数、书签、可搜索性及最后修改页；不能用修改前的截图为修改后的文件背书。

## 曾出现过、应能被检查发现的失败

- 同一行的根号和后续数字分属不同块，导致后一段的中文起点落进前一段：重组逻辑段落，并检测真实文字范围交叠。
- 正文以 “Figure 3 shows …” 开头，被误当成 “Figure 3: …” 图注而缩小字号：用语义和位置区分图注，不只匹配单词 Figure。
- 页首只有跨页句子的几个词，被误判成图例而居中：短文本不自动等于图内标签。
- 两侧最终页数一样，但内容越来越错位：按逻辑单位检查配对和共享分页，页数相同不是合格依据。
- 所有公式完整保留在左侧，右侧却缺少一个负号或变量解释：两侧分别检查，不能用英文侧的存在替代中文侧的完整性。
